# Director Network Analysis

## Overview

This project analyses director-company relationships using Python and network analysis techniques.

The analysis uses graph-based methods to identify influential directors and important connections within corporate networks, supported by Forbes Global 2000 company data.

## Key Features

- Data cleaning and preprocessing
- Company-director relationship analysis
- Network graph construction
- Degree centrality analysis
- Betweenness centrality analysis
- Dataset merging and aggregation
- Forbes Global 2000 data integration
- Network visualisation

## Tech Stack

- Python
- Jupyter Notebook
- Pandas
- NetworkX
- Matplotlib
- Excel / CSV datasets

## Project Workflow

Data  
→ Cleaning  
→ Relationship Mapping  
→ Network Construction  
→ Centrality Analysis  
→ Data Integration  
→ Visualisation  
→ Insights

## Network Measures Used

- Degree Centrality
- Betweenness Centrality
